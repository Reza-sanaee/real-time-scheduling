# Periodic Real-Time Scheduling Simulator: RM, DM, and EDF

A Python discrete-time simulator compares rate-monotonic, deadline-monotonic, and earliest-deadline-first scheduling on one and two cores. It generates schedules, completion/deadline statistics, and utilization for periodic tasks and supports analysis of embedded real-time design tradeoffs.

## Technical highlights

- Implemented and compared RM, DM, and EDF scheduling for periodic workloads on single- and dual-core simulations.
- Generated per-core schedules and deadline statistics; analyzed utilization, priority inversion, and schedulability assumptions.
